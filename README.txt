# Happy Birthday Risita 💖

Open `index.html` in a modern browser.

Features:
- Responsive HTML/CSS/JavaScript birthday page
- Risita photo gallery using the uploaded photos
- Animated balloons, sparkles, hearts and confetti
- Surprise popup
- Wish button
- Browser-generated Happy Birthday melody (no external audio file required)
- Works offline after the folder is extracted

Note: Browsers generally require a user click before audio can play, so use the "Play Birthday Song" button.
